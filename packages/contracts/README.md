# Contratos entre serviços

Os esquemas JSON em `schemas/` são a fronteira versionada entre o motor Python e a API. A versão principal só muda quando houver incompatibilidade. Existem contratos para candles, qualidade, estado de mercado, inferência, decisão, paper trading, backtesting, promoção, holdout, versões de modelo, monitoramento, integração e contexto econômico.
